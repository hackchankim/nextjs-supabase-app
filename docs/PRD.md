# 교회 테마 마피아 게임 MVP PRD

## 🎯 핵심 정보

**목적**: 교회 레크리에이션 행사에서 10-20명이 각자 모바일 브라우저로 접속해 앱 설치 없이 즉시 즐기는 실시간 마피아 게임을 제공한다
**사용자**: URL 하나로 바로 참여하려는 교회 성도 10-20명과, 게임 전체를 운영하는 진행자 1명

---

## 🚶 사용자 여정

```
[참가자]
1. 입장 허브 페이지
   ↓ 닉네임 입력 → 입장 버튼
2. 대기실 페이지 (다른 성도 모집 대기)
   ↓ 진행자가 게임 시작 → 자동 이동
3. 게임 플레이 페이지
   ↓ 역할 카드 확인 (1회 애니메이션)

4. [낮 페이즈] 전체 채팅 토론 → 투표
   ↓ 진행자 투표 마감 → 최다 득표자 탈락

5. [밤 페이즈]
   이단 → 비밀 채팅 + 제거 대상 선택
   담임목사 → 조사 대상 선택 (결과 본인에게만 알림)
   중보기도자 → 보호 대상 선택
   성도 → 기도 대기 화면
   ↓ 결과 처리 후 낮으로 반복

6. 승리 조건 달성 → 게임 종료 화면 (승리 팀 발표)

[진행자]
1. 입장 허브 페이지
   ↓ 진행자 PIN 입력
2. 진행자 대시보드 페이지
   스크린에는 [스크린 탭] 띄우고 / 개인 폰에서 [제어 탭] 조작
   ↓ 참가자 확인 → 게임 시작 → 페이즈 전환 반복 → 게임 종료
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 닉네임 입장 | 닉네임 입력 후 세션 토큰 발급, 로그인 없이 즉시 참가 | 회원가입 없는 즉시 참가가 일회성 행사의 핵심 | 입장 허브 페이지 |
| **F002** | 진행자 PIN 입장 | 4자리 PIN으로 진행자 권한 획득 | 게임 제어 권한 구분을 위한 최소 수단 | 입장 허브 페이지 |
| **F003** | 대기실 실시간 목록 | 접속 참가자 닉네임 목록 실시간 표시 | 참가자가 제대로 입장했는지 확인하는 핵심 화면 | 대기실 페이지 |
| **F004** | 역할 자동 배분 | 인원수 기반 선/악 역할 무작위 배분 후 게임 시작 | 공정한 역할 분배가 게임의 시작점 | 대기실 페이지, 진행자 대시보드 페이지 |
| **F005** | 역할 카드 공개 | 게임 시작 시 개인 폰에 자신의 역할 1회 표시 | 비밀 역할 확인이 마피아 게임의 핵심 경험 | 게임 플레이 페이지 |
| **F006** | 낮/밤 페이즈 전환 | 진행자 제어로 페이즈 전환, 전원 화면에 실시간 반영 | 게임 진행의 근간이 되는 상태 관리 | 게임 플레이 페이지, 진행자 대시보드 페이지 |
| **F007** | 전체 채팅 | 낮 페이즈에 전원이 참여하는 실시간 채팅 | 토론으로 이단을 색출하는 게임의 핵심 메카닉 | 게임 플레이 페이지 |
| **F008** | 이단 전용 채팅 | 이단 역할끼리만 보이는 비밀 채팅방 | 이단 팀의 작전 채널, 게임 긴장감의 원천 | 게임 플레이 페이지 |
| **F009** | 낮 투표 시스템 | 퇴장 대상 선택 + 집계, 진행자 마감 후 최다 득표자 탈락 | 선 팀의 핵심 공격 수단 | 게임 플레이 페이지, 진행자 대시보드 페이지 |
| **F010** | 밤 행동 | 역할별 특수 행동 (이단: 제거 / 담임목사: 조사 / 중보기도자: 보호) | 밤마다 발생하는 핵심 게임 메카닉 | 게임 플레이 페이지 |
| **F011** | 생존 현황 | 생존/탈락 플레이어 목록 실시간 표시 | 게임 진행 상황 파악의 기본 정보 | 게임 플레이 페이지, 진행자 대시보드 페이지 |
| **F012** | 스크린용 현황판 | 역할 비공개 상태로 닉네임·생존 현황만 표시 (빔프로젝터용) | 스크린에 역할이 노출되면 게임이 망가지므로 분리 필수 | 진행자 대시보드 페이지 |
| **F013** | 진행자 전용 제어판 | 역할 포함 전체 현황 + 게임 컨트롤 (진행자 개인 폰에서만 조작) | 진행자만 볼 수 있는 비밀 정보로 공정한 게임 운영 | 진행자 대시보드 페이지 |
| **F014** | 승리 조건 판정 | 선/악 승리 조건 자동 체크 후 게임 종료 및 결과 표시 | 게임의 명확한 결말 제공 | 게임 플레이 페이지, 진행자 대시보드 페이지 |

## 📄 페이지별 상세 기능

### 입장 허브 페이지

> **구현 기능:** `F001`, `F002` | **접근:** 공개 (URL/QR코드 직접 접속)

| 항목 | 내용 |
|------|------|
| **역할** | 참가자와 진행자를 구분해 각각의 게임 흐름으로 안내하는 시작점 |
| **진입 경로** | 진행자가 공유한 URL 또는 QR코드 스캔 |
| **사용자 행동** | 닉네임 입력 후 입장 / 또는 "진행자 입장" 버튼 → PIN 입력 |
| **주요 기능** | • 닉네임 입력 폼 + UUID 세션 토큰 발급 (localStorage 저장)<br>• 진행자 PIN 입력 모달 (4자리)<br>• 게임 제목 및 교회 테마 입장 안내 |
| **다음 이동** | 닉네임 입장 성공 → 대기실 페이지 / 진행자 PIN 성공 → 진행자 대시보드 페이지 |

---

### 대기실 페이지

> **구현 기능:** `F003`, `F004` | **접근:** 닉네임 입장 후

| 항목 | 내용 |
|------|------|
| **역할** | 게임 시작 전 참가자 모집 현황을 실시간 확인하는 대기 공간 |
| **진입 경로** | 입장 허브 페이지에서 닉네임 입장 성공 후 자동 이동 |
| **사용자 행동** | 다른 참가자 입장 대기 / 진행자는 인원 확인 후 게임 시작 |
| **주요 기능** | • 접속 참가자 닉네임 목록 (Supabase Realtime 구독)<br>• 현재 참가 인원 / 최소 인원 표시<br>• **[게임 시작]** 버튼 (진행자만 노출) → 인원수 기반 역할 자동 배분 실행 |
| **다음 이동** | 게임 시작 → 전원 자동으로 게임 플레이 페이지 이동 |

### 게임 플레이 페이지

> **구현 기능:** `F005`, `F006`, `F007`, `F008`, `F009`, `F010`, `F011`, `F014` | **접근:** 게임 시작 후 자동 이동

| 항목 | 내용 |
|------|------|
| **역할** | 참가자가 역할 확인·채팅·투표·밤 행동 전 과정을 수행하는 핵심 게임 화면 |
| **진입 경로** | 진행자 게임 시작 후 Realtime 이벤트로 전원 자동 이동 |
| **사용자 행동** | 역할 확인 → 낮 채팅·투표 → 밤 역할별 행동 반복 |
| **주요 기능** | • 역할 카드 모달 (게임 시작 시 1회, 탭하면 닫힘)<br>• 상단 배너: 현재 페이즈(낮/밤) + 라운드 번호<br>• **전체 채팅** 탭: 낮 페이즈에만 입력 활성화<br>• **이단 채팅** 탭: 이단/이단교주 역할에게만 표시, 밤 페이즈 입력 활성<br>• 투표 패널 (낮): 살아있는 플레이어 버튼 목록, 1인 1표, 중복 방지<br>• 밤 행동 패널: 역할별 UI 분기 (이단: 제거 / 담임목사: 조사 / 중보기도자: 보호 / 성도: 기도 대기 메시지)<br>• 생존 플레이어 목록 실시간 표시<br>• 승리 시 결과 화면 오버레이 |
| **다음 이동** | 승리 조건 달성 → 결과 화면 표시 후 대기 |

### 진행자 대시보드 페이지

> **구현 기능:** `F004`, `F006`, `F009`, `F011`, `F012`, `F013`, `F014` | **접근:** 진행자 PIN 입장 후

| 항목 | 내용 |
|------|------|
| **역할** | 진행자가 스크린용 현황 표시와 개인 게임 제어를 탭으로 분리해 운영하는 전용 화면 |
| **진입 경로** | 입장 허브 페이지에서 PIN 입력 성공 후 이동 |
| **사용자 행동** | 스크린에 [스크린 탭] 띄우고, 개인 폰에서 [제어 탭]으로 전환해 게임 운영 |
| **주요 기능** | • **[스크린 탭]**: 닉네임 + 생존/탈락 여부만 표시 (역할 비공개), 투표 집계 실시간 표시<br>• **[제어 탭]**: 닉네임 + 역할 + 생존 여부 전체 공개, 수동 탈락 처리 버튼<br>• 페이즈 전환 버튼 (낮 → 밤, 밤 → 낮)<br>• 투표 마감 버튼 → 최다 득표자 자동 탈락 처리<br>• 밤 행동 완료 현황 (누가 행동 완료했는지 체크)<br>• 시스템 메시지 발송 (전체 공지)<br>• 게임 종료 / 리셋 버튼 |
| **다음 이동** | 게임 종료 → 결과 화면 / 리셋 → 대기실 페이지 |

## 🛠️ 기술 스택

### 프론트엔드
- **Next.js 15** (App Router) - 풀스택 프레임워크
- **React 19** - UI 라이브러리
- **TypeScript 5.6+** - 타입 안전성

### 스타일링 & UI
- **Tailwind CSS v3** - 유틸리티 CSS 프레임워크
- **shadcn/ui** - 컴포넌트 라이브러리 (Button, Card, Dialog, Tabs, Badge, Avatar, ScrollArea, Sonner)
- **Lucide React** - 아이콘

### 백엔드 & 실시간
- **Supabase PostgreSQL** - 게임 데이터 저장
- **Supabase Realtime** - 채팅·플레이어 목록·게임 상태 실시간 동기화
- **Supabase RLS** - 이단 채팅 채널 접근 제어 (이단 역할만 열람 가능)

### 배포
- **Vercel** - Next.js 최적화 호스팅
